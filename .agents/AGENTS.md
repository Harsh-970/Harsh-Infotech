# Workspace Rules & AI Constraints

These instructions govern how the AI assistant handles project creation, GitHub integration, and repository privacy.

## GitHub Integration Rules

1.  **New Project/Feature Prompts**:
    *   Whenever starting a new feature, project, or module from scratch, the AI assistant **MUST** explicitly ask the user:
        > *"Should I push this to GitHub and create a new repository for it?"*
    *   Wait for the user's explicit consent before configuring remotes or initiating new repositories.

2.  **Repository Privacy Policies**:
    *   Unless explicitly overridden by the user, **all new repositories created on GitHub MUST be set to PRIVATE**.
    *   Do not publish new repositories as public.

3.  **Website Scope**:
    *   The website repository (`Harsh-970/Harsh-Infotech`) must remain **PUBLIC** for now.
